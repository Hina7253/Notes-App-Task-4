# Notes App (Java File I/O) Elevate-Labs-Task-4

This is a simple **Notes Manager Application** built in Java as part of the Elevate Labs Internship (Task 4).
The project demonstrates how to use **FileWriter** and **FileReader** in Java for persistent data storage.

---

## 📌 Objective

* Create a text-based Notes App.
* Save notes in a text file using **FileWriter**.
* Retrieve notes from the text file using **FileReader / BufferedReader**.

---

## ⚙️ Tools & Technologies

* Java
* VS Code / IntelliJ IDEA
* Git & GitHub

---

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/Hina7253/Notes-App-Task-4.git
   ```
2. Open the folder in VS Code or IntelliJ.
3. Compile the Java file:

   ```bash
   javac NotesApp.java
   ```
4. Run the program:

   ```bash
   java NotesApp
   ```

---

## 📝 Features

* Add notes (stored in `notes.txt`).
* View saved notes.
* Exit the application safely.
